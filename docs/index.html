📌 Overview

POS App is a web-based Point of Sale application designed to handle sales transactions efficiently. The application supports role-based access, allowing different features for different users.

👤 Available Roles

Role Description
User Perform sales transactions
Admin Manage transactions and master data

🚀 Getting Started

To start using the POS App, open the application URL and log in using your assigned credentials.

👤 User Guide

🔐 Login

  1. Open the POS App website
  2. Enter your username and password
  3. Click the Login button
  4. You will be redirected to the Dashboard

📊 User Dashboard

  • Navigate to Transactions
  • View general application information

🛒 User Transactions

  1. Open the Transactions menu
  2. Select product(s)
  3. Enter quantity
  4. Total calculated automatically
  5. Click Save / Submit

Result: Transaction recorded in the system.

🛠️ Admin Guide

📊 Admin Dashboard

📑 Admin Transactions

  • View transaction list
  • Monitor sales activity

⚙️ Configurations

🗂️ Categories

  1. Configurations → Categories
  2. Add Category
  3. Enter name → Save

📦 Products

  1. Configurations → Products
  2. Add Product
  3. Fill details → Save

❓ FAQ & Troubleshooting

Why is the Configurations menu not visible?
Ensure you are logged in using an Admin account.

Why don’t products appear in the Transactions menu?

  • Products added by Admin
  • Products assigned to a category
